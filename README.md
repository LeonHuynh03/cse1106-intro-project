# cse1106-intro-project

##Introduction to GitHub and Software Development

## Programing Language: 
- Linux
- GitHub

## Description: This program was created as an introduction to GitHub, Git and software development. It demonstrates how to create repositories and manage source-code with Git and upload Project into GitHub.

## How to run: 
- Clone the repositories
- Run the files as Window Terminal
- Compile the sources file
- Run the program

## What I learned: from this project I learned how to use Git and GitHub to manage source-code. I also learned how to initialize a Git repository, stage and commit files, connect to local repository to GitHub using SSH and push changes to a remote repository.
